# UI тренажёра (стиль «Промышленный HUD»)

Макеты: репозиторий VR_UI. Спрайты рисует `tools/unity_sprites.py` (белые формы, цвет задаётся в Unity).

## Как собрать окно «Лобби»
1. Меню **Koks → Build UI → 2. Собрать окно «Лобби» (префаб)**. Пункт 1 (шрифты и спрайты) запускается сам.
2. Результат: `Assets/Koksohim/UI/Prefabs/LobbyWindow.prefab`.
3. Для проверки: открыть сцену, **Koks → Build UI → 3. Поставить «Лобби» в открытую сцену**.

События окна (компонент `LobbyWindow`): `onStartModule(int)` и `onFreeInspect`. Подключаются в Inspector.
Старые панели в сценах не удаляются и не меняются.
